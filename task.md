# Project: AI-Powered Employee Work Activity & Time Tracker

## Primary Requirements & Key Features

1. **Employee Authentication:** Secure role-based login for employees and administrators with session auditing and auto-invalidation on account deactivation.
2. **Automatic Time Tracking:** Track employee working hours, breaks, and total net work duration with real-time digital timer display and pause/resume lifecycle controls.
3. **Activity Monitoring:** Monitor active and idle time intervals based on keyboard and mouse interaction events while strictly preserving privacy (zero raw keystroke logging).
4. **Project-Wise Time Tracking:** Track time spent specifically on assigned projects and granular individual tasks.
5. **AI-Based Activity Analysis:** Analyze employee work patterns and identify unusual activity using Machine Learning (Isolation Forest with explainable attribution rules).
6. **AI Work Summary:** Automatically generate intelligent daily/historical work summaries synthesizing employee task velocity, logged active ratios, and milestone updates.
7. **Admin Dashboard:** Real-time visibility into active employee presence, live workforce interaction streams, project progress, and natural-language workforce assistant queries.
8. **Reports & Analytics:** Generate daily, weekly, and monthly aggregated productivity reports with multi-column CSV export.
9. **Activity History:** Comprehensive inspection of employee-wise work sessions, break intervals, and raw interaction telemetry logs.
10. **Employee Management:** Add employees, assign projects, manage project statuses, toggle account access, and securely reset passwords.
