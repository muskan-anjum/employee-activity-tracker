How WorkAI Machine Learning Anomaly Detection Operates

ETHICAL WORKFORCE AI

The WorkAI ML engine trains an Isolation Forest algorithm over normalized high-dimensional interaction features: active/idle ratio, interaction frequency (events per active second), and keyboard-to-mouse density. Outliers are isolated with shorter average path lengths in recursive tree partitioning.

Privacy First: Keystroke content is never captured.
Explainable Output: Every flagged record includes human-readable rationale.
Decision Support: Model flags are statistical outliers for review, not disciplinary proof.
